## 1. 项目背景与目标

星座文化在年轻人中长期具备高传播度与话题性。用户希望有一个**轻量级、无需注册、即用即走**的娱乐工具：输入两个人的星座、出生年份与性别，即刻得到两人在「恋人 / 夫妻 / 朋友」三种关系下的契合度结论，并可保存为图片用于社交分享。

**产品目标：**

1.  entertainment：提供有趣、可分享的星座速配结果。
2.  低门槛：无注册、无登录、无历史记录，打开即可使用。
3.  可传播：结果一键保存为图片，天然适配朋友圈 / 小红书 / 微信分享。
4.  可扩展：预留 AI 接口，未来可输出更个性化、更「有梗」的解读文案。

## 3. 功能范围

### 3.1 本期范围（MVP）

- [x] 通过选择器输入两个人的星座、年龄或出生年份（可切换）、性别，全程无需键盘输入
- [x] 根据星座计算三种关系契合度：恋人 / 夫妻 / 朋友
- [x] 展示双方星座特点
- [x] 单页面汇总三类结果
- [x] 结果保存为图片
- [x] 纯前端实现，无注册、无历史记录

### 3.2 AI 增强（已实现，可选触发）

- [x] 结果页**默认展示算法结论**，AI 作为「深度解读」由用户主动点击触发，不阻塞主流程
- [x] AI 分别分析双方星座性格，并从 **恋人 / 夫妻 / 朋友** 三个维度打分 + 解读
- [x] SSE 流式输出，按分段逐块渲染，不用等全文生成完
- [x] AI 分数以算法分为锚点（默认 ±12，最多 ±18），并在界面上并列展示与算法分的差值
- [ ] AI 生成专属配对昵称 / 文案海报

> ⚠️ **安全提示**：API Key 只存在服务端环境变量，前端不接触。生产环境必须经后端代理转发（`server/server.js` 已实现），不要让前端直连大模型接口，也不要明文硬编码 Key。

### 3.3 明确不做

- 用户注册 / 登录
- 历史记录存储（本地或云端）
- 账号体系与数据分析后台
- 精确占星排盘（本产品为娱乐向，基于太阳星座）

## 4. 用户流程

```
打开页面
   ↓
输入 TA 与我（星座 / 年龄或出生年份 / 性别）
   ↓
点击「开始速配」
   ↓
结果页：星座特点 + 恋人 / 夫妻 / 朋友 三类契合度
   ↓
   ├─ 点击「保存为图片」→ 生成海报 → 分享
   └─ 点击「重新测试」→ 返回输入页
```

**异常与边界：**

- 未选择星座即点击开始 → 提示补全信息。
- 年龄 / 出生年份由选择器限定在合法范围，不存在非法输入；默认预选年龄，用户无需填写。
- 同一星座配对 → 正常输出（同星座有专属文案）。

## 5. 功能详细设计

### 5.1 输入模块

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 星座（A / B） | 12 宫格卡片点选 | 是 | 含符号与名称，选中高亮并在标签右侧回显星座名 |
| 年龄 / 出生年份（A / B） | 滚轮选择器 + 模式切换 | 是（有默认值） | **不提供自由输入**。顶部「按年龄 / 按出生年份」两个 Tab 切换：年龄 18–60 岁，年份范围与之对应（今年−60 ~ 今年−18）；切换时自动换算并保持所选年龄不变。滚轮支持滑动与点击，选中项居中高亮，上下渐隐。用于计算年龄差，作为契合度微调因子 |
| 性别（A / B） | 胶囊按钮（男 / 女） | 否 | 点选后可再次点击取消；仅用于展示，不影响基准算法 |

### 5.2 星座特点展示

展示两个星座各自的：元素属性（火/土/风/水）、性格关键词、简短特点描述。

### 5.3 契合度计算（娱乐向规则）

契合度基于「星座元素关系 + 特定星座组合加成 + 年龄差微调」的综合评分模型，输出 0–100 分：

- **元素关系**：火火、土土等同元素组合；火风、土水等互补组合得分较高；火水等冲突组合得分较低。
- **组合加成**：三分相（如白羊×狮子）等经典高契合组合加分。
- **年龄差**：由滚轮选择的年龄（或出生年份自动换算）计算；年龄差越大，恋人/夫妻维度适度扣分，朋友维度影响更小。
- 结果按分数区间映射为文案：天生一对 / 相当默契 / 需要磨合 / 挑战不小。

> 算法为**娱乐性规则引擎**，非科学占星；结果仅用于娱乐与分享。

### 5.4 结果展示模块（单页汇总）

一个页面完整呈现，自上而下分为四段：

1. **综合契合指数**：居中环形进度 + 大号分数，左右分布双方星座（符号、名称、元素、年龄），下方一句话总评（如「高度契合，越处越甜」）。
2. **三张关系卡片**：**恋人 / 夫妻 / 朋友**，每张含大号分数、横向进度条、等级徽章（天作之合 / 高度契合 / 相当不错 / 需要磨合 / 挑战不小）、一句话解读；三卡用金粉、紫青、青绿三套配色区分。
3. **性格速览**：双方星座的元素标签、性格关键词与简短描述。
4. **操作区**：保存为图片、重新测试。

结果页带入场动画：环形与进度条从 0 展开，分数数字滚动至最终值。

### 5.5 保存为图片

- 点击「保存为图片」将结果区渲染为一张竖版海报（Canvas 生成 PNG）。
- 海报内容：双方星座、三类契合度分数与结论、品牌水印。
- 移动端长按图片亦可保存。

### 5.6 AI 深度解读（已实现）

**交互位置**：结果页底部（性格速览之后、操作按钮之前），一个折叠状态的「AI 深度解读」面板。

**触发方式**：点击「让 AI 分析」→ 展开面板 → 流式输出，边生成边渲染。

**面板结构**：双方性格各一段（两列）→ 恋人 / 夫妻 / 朋友三段（含 AI 分数与「算法 xx · ±n」差值）→ 一句总结。

**入参**（前端只传索引与数值，不传自由文本，避免提示词注入）：

| 字段 | 说明 |
| --- | --- |
| `a` / `b` | `sign`（0–11）、`age`、`gender`，均由前端选择器产生 |
| `base` | 算法算出的恋人 / 夫妻 / 朋友 / 综合分，作为 AI 打分的锚点 |
| `relation` | 可选，用户关心的关系，留空则三个维度都评 |

**输出协议**：`POST /api/ai/analyze` 返回 `text/event-stream`，事件类型为 `meta` / `delta` / `done` / `error`。

**分段格式**：模型按 `<<<A>>>`、`<<<B>>>`、`<<<COUPLE>>>`、`<<<SPOUSE>>>`、`<<<FRIEND>>>`、`<<<SUMMARY>>>` 六个标记输出，关系段第一行为分数。前端按标记定位渲染，标记未完整到达时先剥离，避免闪出半截字符。

**失败降级（三层）**：
1. 服务可用且已配置 Key → 真实 AI 流式；
2. 服务可用但未配置 Key → 本地模拟流式，界面标注「演示模式」；
3. 直接双击 HTML 打开 → 尝试连本地服务，失败则走本地模拟，保证原型可演示。

AI 不可用时算法结果完全不受影响，仅有 AI 面板提示失败。

**提示词**：完整设计与正文见 `design/AI提示词设计.md`，实际生效的文本在 `server/prompt.js`。

## 6. 数据结构设计

```ts
// 星座
interface Zodiac {
  name: string;        // 白羊座
  symbol: string;      // ♈
  element: 'fire' | 'earth' | 'air' | 'water';
  traits: string[];    // ['热情', '直率']
  desc: string;        // 特点描述
}

// 用户输入（年龄字段兼容两种填法）
interface Profile {
  sign: number;                  // 星座索引 0-11
  mode: 'age' | 'year';          // 当前选择模式
  age?: number;                  // 年龄模式下的值（18-60）
  year?: number;                 // 出生年份模式下的值
  gender?: 'male' | 'female';    // 可为空
}

// 匹配结果
interface MatchResult {
  couple:  { score: number; level: string; text: string };
  spouse:  { score: number; level: string; text: string };
  friend:  { score: number; level: string; text: string };
}
```

**元素关系基准分（示例）：**

| 组合 | 火 | 土 | 风 | 水 |
| --- | --- | --- | --- | --- |
| 火 | 72 | 52 | 86 | 48 |
| 土 | 52 | 68 | 58 | 78 |
| 风 | 86 | 58 | 74 | 60 |
| 水 | 48 | 78 | 60 | 80 |

## 8. 界面与交互要点

- 首页以深空星空 + 柔光星云为主视觉，突出输入区与 CTA。
- 星座选择使用 12 宫格可视化卡片，选中高亮，降低选择成本。
- 年龄 / 出生年份使用滚轮选择器，Tab 一键切换，符合移动端操作习惯，避免键盘输入。
- 两卡之间以圆形「VS」徽章连接，强化"两个人"的关系感。
- 结果页用环形综合指数 + 三色关系卡（进度条）区分契合度，等级徽章直观可读。
- 结果页入场带数字滚动与进度动画，提升"揭晓感"。
- 强引导「保存为图片」，形成分享闭环；海报为竖版，适配社交平台。
- 提供「重新测试」入口，鼓励多次尝试不同组合。
- 移动端优先，760px 以下自动切换单列布局。

## 10. 验收标准

1. 可选择双方星座；年龄与出生年份通过滚轮选择器选择，并可随时切换两种模式且年龄保持一致；性别可选；全流程无需键盘输入。
2. 结果页在一屏内展示双方特点与恋人/夫妻/朋友三类结果。
3. 点击保存可得到一张包含关键结果的 PNG 图片。
4. 全流程无注册、无登录、无历史记录。
5. 单个 HTML 文件可直接双击在浏览器打开运行；该模式下 AI 走本地演示，启动 `server/server.js` 并配置 Key 后自动接入真实 AI。
6. 未填必填项时有明确提示。
7. 结果页默认展示算法结论，AI 分析必须由用户主动点击才发起请求。
8. AI 分析以 SSE 流式逐段呈现；服务未启动或未配置 Key 时页面不报错，算法结果完整可用。
9. AI 的恋人 / 夫妻 / 朋友分数与算法分数并列展示，差值方向可读。
